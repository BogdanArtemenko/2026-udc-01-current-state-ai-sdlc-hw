# Task 3 — Аналіз токенів та вартості

| Метрика      | Значення        |
| ------------ | --------------- |
| Файлів       | 8               |
| Усього токенів | **1 913**     |
| Усього символів | 7 383        |

Топ файлів за токенами:

| Файл                       | Токени | Частка |
| -------------------------- | ------ | ------ |
| `components/TodoList.tsx`  | 489    | 25.6%  |
| `AGENTS.md`                | 320    | 16.7%  |

Тобто увесь код проєкту вміщується в ~1.9k токенів — мізерна частка вікна
сучасних моделей (200k+). Вартість «впихнути весь проєкт у контекст» незначна;
основні витрати — це **діалог/ітерації агента**, а не разове читання коду.

## Витрати на фічу (сесія Plan → Agent)

Оцінка за лог сесії побудови `TodoList`:

| Етап              | Input токени | Output токени |
| ----------------- | ------------ | ------------- |
| Plan (структура)  | ~6 200       | ~1 100        |
| Agent ітерація 1  | ~8 900       | ~1 800        |
| Agent ітерація 2  | ~9 400       | ~700          |
| **Разом**         | **~24 500**  | **~3 600**    |

### Оцінка вартості

За цінами Claude Sonnet (input $3 / 1M, output $15 / 1M):

- input: 24 500 × $3 / 1 000 000 = **$0.0735**
- output: 3 600 × $15 / 1 000 000 = **$0.054**
- **Разом ≈ $0.13 за фічу.**

> Примітка: input домінує за обсягом, але output дорожчий за токен (×5), тож
> «балакучі» відповіді б'ють по гаманцю сильніше, ніж великий контекст.

## Висновки про оптимізацію

1. **Контекст — не вузьке місце на малому проєкті.** 1.9k токенів коду нічого не
   варті; різати `node_modules`/білди через `.cursorignore` важливо радше для
   *сигналу/уваги* моделі, ніж для ціни. На великому моно-репо висновок зміниться.
2. **Платимо за ітерації, не за читання.** Друга Agent-ітерація (виправлення зайвого
   `useCallback`) коштувала майже як перша. Якісний план у Plan-режимі **до** генерації
   зрізає кількість ітерацій — найдешевший спосіб економити.
3. **Output дорожчий — проси стисло.** Прохання «показати лише diff, без переказу коду»
   зменшує output-токени, які коштують ×5 проти input.
